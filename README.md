# Haven — Homepage

The homepage for **Haven**, a custom luxury home builder in Melbourne (Essendon, Aberfeldie, Moonee Ponds & Ascot Vale).

Built with plain HTML, CSS and JavaScript, plus.

## Sections

- Hero banner
- Scrolling image gallery
- Philosophy
- Featured projects (Calibre, Obsidian, Ascot Residence, Small House)
- Collaborators
- Client video stories

## Project structure

```
index.html      Homepage
css/style.css   Styles
js/script.js    Animations and interactions
images/         Photos and favicon
```

## Run it

No build step needed. Open `index.html` in a browser.
